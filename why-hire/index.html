Merged upstream Go contribution · Grafana

Delivered a Grafana ShortURL compatibility fix that was approved and merged.

The compatibility endpoint had treated Kubernetes namespace names such as default and org-5 as numeric Grafana organization IDs, producing malformed response URLs. The malformed link could send a recipient to the wrong organization and cause the short-URL lookup to fail. I directed a fix that uses the active numeric organization ID from the authenticated request for non-Cloud response URLs, omits orgId for Grafana Cloud, and preserves configured application subpaths.

Result: merged into Grafana main as commit 6a03817. Five handler-level regression cases cover default, named, and conflicting namespaces; Cloud with populated and absent request organization IDs; and an AppURL configured with an application subpath.
