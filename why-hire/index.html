01 / Upstream evidence

One merged repair. One difficult implementation moving toward review.

Merged · September 25, 2026 Go / ShortURL API / PR #131070

Restore valid organization links in the short-URL API.

The compatibility endpoint used a resource namespace where it needed a numeric organization ID, producing malformed response links. I contributed the repair and five Go regression cases. Grafana approved and merged the pull request.

The defect

Namespace values such as default and org-5 were being treated as organization IDs. These are different identifiers.

The correction

Use the authenticated numeric organization ID for non-Cloud links, omit orgId for Grafana Cloud, and preserve configured application subpaths.

The regression coverage

Five handler-level cases cover default, named, and conflicting namespaces; Cloud with and without an organization ID; and a configured subpath.

Open · Review pending Rust / Tokio macro / PR #8374

Support cfg-gated select! branches without breaking fairness or existing syntax.

Tokio issue #3974 had been open since 2021 and was marked E-hard. The submitted implementation removes disabled branches before generating storage and polling logic, preserving dense branch indices and randomized scheduling behavior. Its feature code and tests have remained unchanged since the first submission; upstream CI passed.

“I've determined your approach probably works. I'll review this once v1.54.0 is out.”

— Darksonn · October 13, 2026

The hard part

Earlier approaches either distorted randomized selection by counting disabled branches or broke supported select! grammar and macro behavior.

The verification

Regression coverage and a controlled 450-invocation compiler study found no unexpected results across Rust 1.88 and 1.98, including the 64-branch boundary.

The current status

The pull request remains open and unmerged. The reviewer has given a positive preliminary assessment and plans to review it after Tokio v1.54.0.
